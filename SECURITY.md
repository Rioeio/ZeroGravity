# Security Policy

## Supported Versions

Only the latest release of ZeroGravity receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ZeroGravity, please do NOT file a public issue.

Instead, please send an encrypted or private email report to:
**security@rioeio.com** (or through GitHub Private Vulnerability Reporting on the repository).

Please include:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Affected versions and environment details (OS, Python version).

### Response Commitment
- **Initial Acknowledgement**: We commit to acknowledging receipt of vulnerability reports within **48 hours**.
- **Assessment & Triage**: We will provide an assessment and timeline for a remediation within 5 business days.
- **Disclosure**: Coordinated public disclosure will take place once a patch is released.
